## First launch

1. Run the setup and open AfterForge.
2. Choose your game. If it is not detected, use Browse to select its installation.
3. Press **Play** (called **Prepare & Play** in some versions).
4. Review any proposed repairs. Windows may ask permission for runtime installation or firewall changes.

For multiplayer over the internet, each player needs Radmin VPN, membership in the same Radmin network, and matching game versions and mods. Use the same private group code in AfterForge's Match Check.

## If something stops you

- **Game not found:** confirm it is installed, then select its folder with Browse.
- **Friends do not appear:** check the Radmin network and Match Check results on both PCs.
- **A repair fails:** read Diagnostics for the specific cause; use Backups to undo a completed change.
- **Setup says files are in use:** close AfterForge, including its tray icon, and Explorer windows showing the installation folder; retry setup.
- **An update cannot be downloaded:** return to this page and check the release notes before installing manually.

Download setup only from this repository's release assets. Published releases include `SHA256SUMS.txt` for checking download integrity; a checksum alone does not prove publisher identity. Windows may show an unknown-publisher prompt for unsigned releases.

## Updates and older versions

AfterForge checks for updates according to its settings. Keep your own backups of saves and user-created maps before changing versions. Older installers are available under All releases.

When reporting a problem, include the AfterForge version, game/edition, the exact error, and a sanitized diagnostic export. Do not post group passwords or private group codes in public issues.
